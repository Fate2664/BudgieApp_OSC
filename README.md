# Budgie Budgeting App
### This is a budgeting app for our OSC module.

Feature list:

  Sign in Page:
  + Account creation and Login.
  + Password and Account database using RoomDB.

  Home Page:
  + Income And Expense Tracking
  + Cashflow Graph
  + Expenses Pie Chart
  + Income Recording
  + Expense Recording

  Budgets and Goals Page:
  +  Budget adding
  +  Goal adding
  +  Adding money to goals
